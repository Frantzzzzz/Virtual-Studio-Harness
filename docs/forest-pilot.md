# Forest 胶囊小样执行基线

日期：2026-11-25。以下是提取前原实验的实际测量，提取版的配置迁移不等于新的 Blender / 模型复跑。

## 效果

- 原有森林白模/LOD，三名条纹胶囊、一个黄色盒子、两张台。
- 宿主提供局部区域与候选站位，程序测得 10 个候选站位、39 条路线连接、14 个勘景视点。
- 动作导演给出 17.625 秒，24 FPS，共 423 帧；没有强制均分镜长，没有视频倍速。
- 摄影首版 6 镜：第 2 镜 7 帧、第 3 镜 44 帧盒子被遮挡。摄影指导换机位，在 6.5 秒增加切点，最终 7 镜。
- 摄影返修期间，人物与道具动画文件哈希未变。
- 423 帧通过本次实际写入回读、声明的走位代理、摄影净空和关键主体采样可见性检查；视频完整解码。

## 测量与限制

- Blender 动作位置回读最大误差约 `1.34e-6` 个场景单位。
- 地形根点误差约 `[-0.00727, 0.00367]` 个场景单位。
- 走位检查采用竖直球体代理及声明障碍，排除 GroundPlants；名称分组不能保证其中全是可穿过植被。
- 摄影检查包括必要头部 / 盒子的采样可见比例至少 0.5 且足够命中采样，不能代替通用视觉质量、语义、抓握或物理评测。
- 胶囊无手臂、腿部步态、骨骼与蒙皮，盒子跟随隐形挂点。
- 视频阶段省略远处背景以加速；检查使用当前完整森林代理几何，没有验证原高细节资产与透明材质。
- 采用 WorldOS 角色指导和部分采样代码，通过两个受限 Codex 角色执行；没有跑完整 WorldOS 应用或原生 camera harness finalize。
- 未验证三方自主协商、跨场 / 跨集状态传递、8 分钟单集、Seedance / Wan 成片。

原始场景、视频、图片、日志、数值记录和角色工单保留在本机实验目录，本仓库仅保留代码与上述摘要。

## 提取后的验证

- 8 项配置与源码检查通过，包括路径解析、缺失输入、场景哈希格式、非法站位、区域边界及输出覆盖源文件的防护。
- 本机实际输入路径检查通过；配置原点与十个候选站位和原实验共享包一致。
- 将原实验输入复制到临时输出目录，实际运行提取版 `compile_actions.py` 和 `compile_camera.py`。
- `motion_samples.json`、`native_motion_samples.json`、`ownership_events.json`、`camera_samples.json` 的解析结果与原实验完全一致，仍为 17.625 秒、423 帧、7 镜。
- 上述检查没有启动 Blender 或模型。提取后未重新生成整套视觉输出，GitHub CI 仅执行无需外部依赖的源码与配置检查。
